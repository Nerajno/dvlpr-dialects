One token layer,
four dialects.

Every surface uses the same token names and the same classes. Five dials change underneath: font, density, and the accent's hue, saturation and lightness. Two more set a second accent for supporting details. Switch surface and mode at the top; everything on this page follows.

Surfaces

Each part of the site speaks its own dialect. Pick one to restyle the page.

Colour

Values are read live from the page, so they always match the surface and mode you're viewing. Each swatch shows its oklch() source value and the nearest sRGB hex for design tools (≈ means the colour is outside sRGB and the hex is clipped). The corner figure is the contrast ratio against --bg.

Type

Body and headings come from --font-body and --font-heading, which each surface resolves. Teach sets its headings in Fraunces.

Progress over perfection

Oct 31, 2026•6 min read•412 views

I used to rebuild the design system every time a site changed. Now there's one spine, and each surface only turns its dials. The blog runs on teach, so links like this one pick up the chalkboard teal.

What I learnt shipping it

Contrast is a number you can check. Every text token clears 4.5:1 on every background, in every surface, light and dark.

The tradeoff

Mono surfaces read tighter. That's the point: notebooks and workbenches are dense on purpose.
