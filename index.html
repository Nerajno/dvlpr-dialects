Dialects

developingdvlpr.com · design tokens

One token layer,
four dialects.

Dialects is the design-token layer behind developingdvlpr.com. One set of token names and classes; four surfaces that each speak them a little differently.

Each surface sets a handful of dials: the font, how dense the type sits, and two accent colours. Everything else — backgrounds, borders, shadows — is worked out from those. Dark mode uses the same dials with the lightness flipped.

Pick a surface and a mode. The whole page follows.

Get started

Install from a tagged release, import the CSS, and set the surface before the page paints.

npm i github:Nerajno/dvlpr-dialects#v0.2.0
@import "@nerajno/dialects/fonts.css";
@import "@nerajno/dialects/tokens.css";
@import "@nerajno/dialects/utilities.css";
@import "@nerajno/dialects/code.css";

Then inline theme-init.js in your <head> with data-surface set. Full setup, including the Tailwind preset, is in the README.

Progress over perfection

Oct 31, 2026•6 min read

I used to rebuild the design system every time a site changed. Now there's one token layer, and each surface only turns its dials. The blog runs on teach, so links like this one pick up Chalkboard Teal.

What I learnt shipping it

Contrast is a number you can check. Every text token clears 4.5:1 on every background, in every surface, light and dark.

The tradeoff

Mono surfaces read tighter. That's the point: notebooks and workbenches are dense on purpose.

Code

Code blocks read the same tokens. Keywords take the action accent and strings take the support accent; functions and constants borrow other surfaces' colours, so no two roles share one.

Set Shiki to the css-variables theme and import code.css.

keyword string function constant comment 
<script setup lang="ts">
import { computed } from 'vue'

type Surface = 'portfolio' | 'learn' | 'teach' | 'build'
const props = defineProps<{ surface: Surface; posts: number }>()

// One token layer, four dialects
const label = computed(() => `Now reading: ${props.surface}`)
const isBusy = props.posts > 12 && true
</script>

Questions

Short answers about what Dialects is and how to use it.

What is Dialects?

A design-token layer for a set of related sites. One layer of CSS custom properties that every site shares, with four surfaces that each change a few dial variables: font, density and two accent colours.

What is a dialect?

How one surface speaks the shared tokens. Every surface uses the same token names and classes, but sets its own dials, so it gets its own font, density and colours.

Why OKLCH instead of hex?

Because equal steps look equal to the eye. That lets every colour be calculated from a few dials and checked for contrast. Hex values are listed for design tools; OKLCH is the source of truth.

What are the accent colours?

Each surface has an action accent for links and buttons, and a support accent for tags and highlights. Portfolio uses Quiet Violet and Signal Indigo; learn, Notebook Ochre and Highlighter Plum; teach, Chalkboard Teal and Pink Chalk; build, Workshop Orange and Blueprint Blue.

Is it accessible?

Yes. Text tokens and the action accent reach at least 4.5:1 on every background, control edges reach 3:1, and every status colour carries a label and a marker shape, so colour is never the only signal.

How do I install it?

Run npm i github:Nerajno/dvlpr-dialects#v0.2.0. Import tokens.css and utilities.css, then inline theme-init.js in your page head to set the surface and mode before first paint. A Tailwind preset is included.
