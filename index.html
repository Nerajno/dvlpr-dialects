Dialects is an open-source OKLCH design-token system by Nerando Johnson for developingdvlpr.com. Every surface uses the same token names and the same classes. Five dials change underneath: font, density, and the accent's hue, saturation and lightness. Two more set a second accent for supporting details. Questions

Short answers about what Dialects is and how to use it.

What is Dialects?

Dialects is an open-source design-token system by Nerando Johnson for developingdvlpr.com. It is one layer of CSS custom properties (tokens) that every site shares, with four surface dialects that change only a few dial variables: font, density and accent colours.

What is a dialect in Dialects?

A dialect is how one surface speaks the shared tokens. The portfolio, learn, teach and build surfaces all use the same token names and classes, but each sets its own dials, so it gets its own font, density and accent colours.

Why does Dialects use OKLCH instead of hex?

OKLCH describes colour as lightness, chroma and hue, and equal steps look equal to the eye. That lets every colour be calculated from a few dials and checked for contrast. Hex values are listed for design tools like Figma, but OKLCH is the source of truth.

What are the Dialects accent colours?

Each surface has an action accent and a support accent: portfolio uses Quiet Violet and Signal Indigo, learn uses Notebook Ochre and Highlighter Plum, teach uses Chalkboard Teal and Pink Chalk, and build uses Workshop Orange and Blueprint Blue. Status colours are Go Green, Caution Yellow, Stop Red and Notice Blue.

Is Dialects accessible?

Yes. All text tokens and the main accent reach at least 4.5:1 contrast against every background, control edges reach at least 3:1, and every status colour is paired with a label and a marker shape so it never relies on colour alone.

How do I install Dialects?

Install it from a tagged GitHub release with npm i github:Nerajno/dvlpr-dialects#v0.1.0, import tokens.css and utilities.css, and inline theme-init.js in the page head to set the surface and light or dark mode before first paint. A Tailwind CSS preset is included.
